# 社保退休缴费月数计算器（网页）

一个纯前端小工具：输入出生日期、法定退休年龄、当前已缴费月数、最低缴费要求后，估算还需要缴纳多少个月社保才能达到退休条件。

## 新增功能

- 退休规则预设：`男职工(60岁)`、`女干部(55岁)`、`女工人(50岁)`，并可叠加弹性延迟退休月数自动带出退休年龄。
- 地区模板：支持`全国常见基线(180)`与地区模板，且可通过“地方调整(月)”进行增减。
- 结果导出：支持一键复制结果文本、下载结果截图 PNG。
- 本地历史：自动记录最近 20 条计算记录（`localStorage`），支持恢复输入、删除单条、清空记录。

## 计算逻辑

满足退休通常需要同时满足：

1. 达到法定退休年龄；
2. 累计缴费达到最低月数（默认 180 个月，可自行修改）。

本工具假设你从现在开始持续按月缴费，输出：

- 距离法定退休年龄的月数；
- 距离最低缴费要求的月数；
- 实际还需缴纳月数（取两者较大值）。

## 快速运行

```bash
cd social-security-retirement-calculator-web
npm test
npm start
```

然后打开浏览器访问 `http://localhost:8080`。

## 文件说明

- `index.html`: 页面结构
- `styles.css`: 页面样式
- `calculator.js`: 计算核心逻辑
- `app.js`: 表单处理与结果渲染
- `tests/calculator.test.mjs`: 计算逻辑单元测试
- `styles.css`: 页面样式（含历史与导出按钮样式）

## 注意

- 此工具用于估算，具体退休政策以当地人社部门最新规定为准。
- 法定退休年龄规则可能因性别、工种、地区和政策变化而不同；预设仅用于快速估算，请以当地政策为准。
- 地区模板默认值用于演示如何配置；实际缴费年限要求请以当地人社部门最新规定为准。
